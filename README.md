# PADALI — сайт группы

Одностраничный сайт на двух языках (EN/SR) с блочной админкой.
Текстовый контент — в MySQL, изображения — на диске, разделы страницы
собираются из блоков и переставляются мышью.

- **Стек**: Node.js 22, Fastify, MySQL 8, шаблоны Eta (рендеринг на сервере)
- **Деплой**: Docker, Coolify
- **Спецификация**: [docs/superpowers/specs/2026-10-03-padali-cms-design.md](docs/superpowers/specs/2026-10-03-padali-cms-design.md)

---

## Запуск локально

```bash
npm install
npm run db:up        # MySQL 8 в контейнере на порту 33061
npm run seed         # миграции + перенос исходного контента + создание админа
npm run dev          # http://localhost:3031
```

Админка: `http://localhost:3031/admin`, вход из `.env.development`.

Остановить базу: `npm run db:down`.

### Тесты

```bash
docker exec padali-mysql-dev mysql -uroot -prootdev \
  -e "CREATE DATABASE IF NOT EXISTS padali_test; GRANT ALL ON padali_test.* TO 'padali'@'%';"
npm test
```

## Деплой в Coolify

1. Подключить репозиторий, тип приложения — **Docker Compose**.
2. Задать переменные окружения (см. `.env.example`). Обязательны:
   `DB_PASSWORD`, `DB_ROOT_PASSWORD`, `SESSION_SECRET`, `PUBLIC_URL`,
   `ADMIN_EMAIL`, `ADMIN_PASSWORD`.
   Секрет сессий: `openssl rand -hex 32`.
3. Добавить **persistent storage** на `/app/data/uploads` — там лежат
   загруженные изображения. Без тома они пропадут при следующем деплое.
4. Развернуть. При первом старте приложение само применит миграции,
   перенесёт контент исходного лендинга и создаст администратора.
5. Войти в `/admin`, сменить пароль не нужно — он задан переменными;
   после первого входа `ADMIN_EMAIL` и `ADMIN_PASSWORD` можно удалить.

Файл `.env` в репозиторий не попадает: переменные задаются в интерфейсе Coolify.

## Из чего состоит

```
src/
├─ blocks/         дескрипторы типов блоков — реестр расширяемости
├─ db/             пул соединений и миграции
├─ repositories/   единственное место, где есть SQL
├─ services/       сборка страницы, обработка картинок, рендеринг, авторизация
├─ routes/         HTTP: публичная часть и админка
└─ views/          шаблоны Eta: раскладка, блоки, админка
public/            css, js, брендовые ассеты
seed-assets/       фотографии для первичного наполнения
data/uploads/      загруженные изображения (том, в git не попадает)
```

### Как устроен контент

| Таблица | Что хранит |
|---|---|
| `blocks` | блок на странице: тип, позиция, видимость, якорь, непереводимые настройки |
| `block_texts` | весь переводимый текст блока, строками `(язык, поле, значение)` |
| `block_media` | связи блока с изображениями |
| `galleries` + `gallery_items` | альбомы и их состав |
| `media` + `media_texts` | файлы, их размеры и описания |
| `pages` / `page_texts` | страница и её мета-теги |

Добавление языка — вставка строки в `locales`, а не изменение схемы.
Если перевода поля нет, показывается значение языка по умолчанию.

## Как добавить новый тип раздела

Два файла, без миграций:

**1. Дескриптор** `src/blocks/<тип>.js` — админка построит форму по нему:

```js
export default {
  type: 'video',
  title: 'Видео',
  description: 'Встроенный ролик с подписью.',
  texts:    [{ key: 'heading', label: 'Заголовок', input: 'text' }],
  media:    [{ key: 'poster',  label: 'Превью' }],
  settings: [{ key: 'url', label: 'Ссылка на ролик', input: 'url', required: true }],
  template: 'blocks/video'
}
```

**2. Шаблон** `src/views/blocks/video.eta`:

```eta
<section class="section wrap"<% if (it.block.anchor) { %> id="<%= it.block.anchor %>"<% } %>>
  <% if (it.block.text.heading) { %><h2><%= it.block.text.heading %></h2><% } %>
  <!-- it.block.settings.url, it.block.first('poster') -->
</section>
```

**3.** Подключить дескриптор в `src/blocks/index.js`.

Доступные типы полей: `text`, `textarea`, `richtext`, `number`, `checkbox`,
`select`, `date`, `url`, `repeater`, `image-picker`, `gallery-picker`.
Поля из `texts` автоматически получают по инпуту на каждый язык.

## Фотогалерея

Альбом и место показа разделены: фотографии лежат в альбоме (`/admin/galleries`),
а блок «Фотогалерея» только ссылается на альбом и задаёт вид.

Поэтому можно:

- поставить на страницу **несколько галерей с разными альбомами**;
- вставить **один альбом в нескольких местах** с разной раскладкой — например,
  лентой из четырёх кадров вверху (`Показать первые N` = 4) и полной сеткой ниже;
- править порядок и подписи **один раз в альбоме** — обновятся все вставки.

Раскладки: сетка, горизонтальная лента, кладка. Число колонок, лайтбокс и
подписи настраиваются в блоке.

## Изображения

При загрузке `sharp` делает webp-версии шириной 320/640/1280/1920 (шире
оригинала не создаёт) и кладёт их рядом с исходником в
`data/uploads/ГГГГ/ММ/`. Имя файла — SHA-256 содержимого: повторная загрузка
того же файла не создаёт дубль, а отдача идёт с `Cache-Control: immutable`.

Файл нельзя удалить, пока он используется хотя бы в одном блоке или альбоме.
